# RoadAid – On-Road Vehicle Breakdown Assistance Finder (React + Node/Express + MySQL)
Features: JWT auth, roles (driver / mechanic / admin), Haversine nearby search, Leaflet map, Socket.io live updates + notifications,
SOS button, fare estimate, mechanic availability, request history & earnings, ratings, admin panel, validation.
1. Put your MySQL password in backend/.env (DB_PASSWORD=...)
2. cd backend && npm install && npm start
3. cd frontend && npm install && npm run dev  -> http://localhost:5173
Admin login: admin@roadaid.com / admin123 (change in backend/.env)
